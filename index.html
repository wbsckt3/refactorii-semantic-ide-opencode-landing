Siempre tú decides, el agente IA es agnóstico

Nada se escribe en tu disco ni en tu repo local ni en un repo remoto. Tú auditas y decides la conveniencia del cambio según tu contexto de trabajo. Descartar simplemente deja el workspace como estaba. El agente es agnóstico, es decir no ejecuta el cambio (git add, PR, commit, merge, etc.) ni de manera local ni remota.

Agentic IDE SaaS

Qué es el IDE?

No es un chat genérico: es un editor sobre el código que estás construyendo el cual manipula el agente de inteligencia artificial.

Capacidad Estado Qué significa para tu código
Web IDE Listo Editas el proyecto en el navegador. El agente escribe en el mismo sitio donde tú lees el código.
Explorer Listo Ves el árbol de archivos. Marcas cuáles viajan con la tarea (Context Pack).
Proyectos Listo Importas carpeta o ZIP. El trabajo es sobre tu código, no sobre un ejemplo vacío.
Agent Listo Pides un cambio en lenguaje natural y recibes un diff aplicado a esos archivos.
Ejecución aislada Listo El agente no corre en tu PC. Tú revisas el resultado en el IDE antes de tocarlo.
Git Listo Cuando aceptas, haces commit a tu repositorio. El token no se queda en el browser.
Diff Listo El cambio se revisa aquí: archivos tocados y diff. Tú apruebas, aplicas o descartas.
LSP Listo Avisos y problemas del archivo abierto: errores, estructura y diagnóstico de este código. El agente trabaja sobre ese mismo árbol, no sobre un paste en el chat.
MCP Listo Declaras una conexión para que el agente use herramientas de tu negocio (Postgres, APIs, Jira, docs) como contexto de este código.
Skills Listo Archivos de convención en tu workspace (.refactorii/skills/). Las activas y el agente las aplica al refactor: Spring, Vue, Postgres, testing, Refactorii.
Multi-agent Listo Orquestación Planner → Coder → Reviewer sobre tu tarea: planifica, escribe el cambio en tu código y lo revisa antes de dejarte el diff.
Contexto del agente

Skills, MCP y LSP se aplican a tu código

No es un chat con un recorte de código. En el Explorer defines el Skill, en el editor ves el LSP, en el panel conectas el MCP. El agente usa eso en la tarea local.
